# 术语表与译名来源

**最后核对：** 2026-10-23
**用途：** 模块内所有显示名以本表为准；`id` 与显示名分离，改译名不改 id。

## 1. 来源分级

| 级别 | 含义 | 采信方式 |
|---|---|---|
| **官方** | Games Workshop 官方中文出版物/官网原文 | 直接采用，标页码 |
| **通行** | 无官方术语表，但百科、官方本地化作品与社区长期一致 | 采用并在表中标注 |
| **无官方** | FFG《Deathwatch》专有机制，没有官方中文版 | 保留现有译名或英文原名，不冒充官方 |

### 来源清单

| 编号 | 来源 | 说明 |
|---|---|---|
| O1 | 《战锤 40000》核心规则 中文版 PDF, 2023-06, <https://warhammer40000.com/wp-content/uploads/2023/06/kIMdsvLTEabDxrUv.pdf> | GW 官方中文，60 页；本机副本 `E:\VTT\assets\reference\wh40k-core-zh.pdf` |
| C1 | 百度百科「死亡守望」<https://baike.baidu.com/item/死亡守望/5014370> | 社区百科，用于药剂师/智库/技术军士/突击兵/毁灭者 |
| C2 | 中文维基「战锤40000：星际战士」 | 官方本地化作品沿用「极限战士」 |
| — | FFG《Deathwatch Core Rulebook》(2010) 英文原书 | 只提供英文原名，不提供中文 |

> **重要事实：** FFG 的《Deathwatch》跑团规则书**没有官方中文版**。
> 因此「官方译文」只在 GW 的 40K 通用词汇层面存在；
> Cohesion、Magnitude、Requisition、Solo/Squad Mode 这类 FFG 专有机制**没有官方译名**，
> 本表不会为它们编造「官方」出处。
