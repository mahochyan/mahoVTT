# 玩家验收清单

以下仍需在你的 Windows 与真实 DGX 上执行，不能因为随附测试通过就自动打勾。

## A. 首次启动

- [ ] 解压为 `E:\VTT\sagas`。
- [ ] node --version 可运行，版本至少 22.16。
- [ ] 双击 start.cmd，网页打开，创建角色，不安装 npm 依赖也能进行按钮操作。
- [ ] 原有相邻项目未被修改。

## B. 完整冒险

1. 接受伊蕾娅委托，任务第一步完成，金币仍为零。
2. 打开营地门，移动至走廊，遭遇哨兵。
3. 攻击、移动、使用回气或药水；检查骰史和 HP。
4. 结束回合，确认两个同伴与敌人顺序行动，不永久停住。
5. 到守卫室，击败四名守卫，取补给箱一次。
6. 尝试重复领取同一箱子，不应得到第二份物品。
7. 进入储藏室，读取账簿和铭文，与米咕对话，取旧药箱。
8. 进入祭坛，击败构装守卫。
9. 先校准，再取钥匙，主线第二步完成。
10. 回到入口，交给伊蕾娅，获得一次 60 金币和 50 经验。
11. 查看结局，应体现校准、证据和救助。
12. 全部敌人击败加补给箱与主线，队伍共 70 金币、185 经验。

## C. 真实模型

- [ ] 网页配置真实 Base URL 与模型 ID，保存测试。
- [ ] 执行 node scripts/ai-ping.mjs --samples 20，保存报告。
- [ ] 确认计划格式成功率与引擎合法性分别显示，不把模型列表成功当完整通过。
- [ ] 自由输入只执行一个动作，角色名不漂移；事实卡与角色面板一致。
- [ ] 思考字段不出现在剧情文本。
- [ ] 队友能正常决定；超时则有明确规则兜底记录。

## D. 恢复和存档

- [ ] 行动后刷新，HP、背包、任务与骰史一致。
- [ ] 断开 DGX：按钮仍可用，自由文本计划失败不造成状态变化。
- [ ] 结算后打断叙事，再重试，不重复扣血或发奖。
- [ ] 关闭程序后重启，战役仍在，AI 自动回合可继续。
- [ ] 导出并导入为新副本，规范状态一致，原战役不被覆盖。
- [ ] 保存备份前关闭服务或使用逻辑导出，不只复制运行中的主数据库文件。

## E. 最终长局

- [ ] 真实模型与真实 Windows 连续三小时游玩，记录每次错误。
- [ ] 检查至少一次模型离线、流中断、刷新、重启与导出导入。
- [ ] 没有因叙事重试重复骰子/奖励；没有角色卡与服务端状态冲突。
- [ ] 有任何未解决问题就不标记最终 M5 完成。

浏览器自动化脚本不替代这份实机清单。报告应记录 Node 版本、服务端模型版本、模型 ID、超时配置、失败样例，而不是只写“全部正常”。
