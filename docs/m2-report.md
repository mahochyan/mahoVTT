# v0.2 M2/M3 进度报告

日期：2026-10-22
基线：`v0.2 M1`（平台 API、角色、能力注册表、迁移）

## 已交付

### 平台外壳与工作台

- 中性「档案库」视觉：石墨黑 + 象牙白 + 冷钢强调；世界主题只作用于卡片与细节。
- 侧栏导航：工作台 / 战役 / 角色 / 世界 / 内容库 / 设置。
- 工作台：继续冒险 hero（世界封面 + 渐变）、统计、战役卡、快速操作、角色名册、世界入口。
- 空状态：无战役时引导创建或导入。

### 战役

- 列表：进行中 / 已归档，归档与恢复、继续、详情。
- 详情：封面、世界、小队、任务、编年史、最近回合、存档信息；改名、导出、归档、删除（二次确认 + `confirm=1`）。
- 归档战役默认不进入工作台 hero。

### 角色

- 名册、创建、详情、编辑、删除。
- 战士 / 游侠 / 牧师；属性派生 HP/AC/攻击/伤害/射程/技能/能力。
- 角色创建后进入名册；创建战役时复制为 `pc`，不回写已开始战役。

### 创建向导

四步：世界 → 角色（新建或名册）→ 队伍确认 → 命名并进入。
- 新建角色在创建战役前写入名册。
- 固定同伴来自世界描述符（沈鸢、洛恩）。
- 真实浏览器 CDP 流程已验证：世界 → 角色 → 队伍 → 标题 → 创建 → `/c/:id` 跑团页。

### 世界 / 内容库 / 设置

- 世界列表与详情（公开世界书；不返回 `dmEntries`）。
- 内容库：怪物 / NPC / 道具 / 地图，只读。
- 设置：AI 模式、Base URL、模型、密钥、JSON 约束、超时、预算、额外参数；保存与测试连接。

### 跑团页兼容

- `/c/:id` 继续使用现有 VTT 界面；`返回` 改为回到平台 `/`。
- 能力按钮改为按 `actor.abilityIds` 渲染：回气 / 瞄准射击 / 疗愈术 / 灯辉术。
- 队伍卡显示能力资源或射程；背包显示当前武器与伤害，修复游侠出现 `回气 undefined` 的问题。

## 验证

- `npm test`：**62 / 62 通过**（含平台 API、角色派生、旧库迁移）。
- 无头 Edge + CDP 真实渲染：
  - 页面：`/`、`/campaigns`、`/campaigns/:id`、`/campaigns/new`、`/characters`、`/characters/new`、`/worlds/:id`、`/library`、`/settings` 均可渲染。
  - 向导全流程可创建战役并跳到跑团页。
  - 390px 宽：无横向溢出（`doc 375 < 390`），侧栏横向滚动已隐藏滚动条。
- 截图：`docs/screenshots/`（dashboard / wizard / campaign / library / mobile / play）。

## 已知缺口（未完成）

1. 跑团页视觉仍是 v0.1 的界面，尚未按中性平台 + 世界主题重构（M4）。
2. 地图仍为几何网格；未接入生成的底图/材质/棋子（M4/M6）。
3. 世界详情、角色卡、设置页未逐张截图；已用 DOM 断言确认可渲染。
4. 导入存档仅在 API 层测试，未在浏览器点击验证。
5. 无 Playwright 自动化；CDP 脚本是手动验证工具，`tests/e2e.py` 仍依赖 Python Playwright。
6. 仅一个世界；内容包与第二世界在 v0.3。
7. 角色/怪物立绘未生成；RGBA 头像需要 matte 处理。
