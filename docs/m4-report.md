# v0.2 M4 进度报告：跑团页视觉与棋子

日期：2026-10-22

## 已交付

- **中性跑团外壳**：顶栏改为 `GRAYLIGHT` 品牌 + 世界名 + 工作台入口；颜色与平台一致（石墨黑、冷钢、象牙白）。
- **世界主题**：战役快照返回 `pack`；前端注入 `--world-accent / --world-tint / --world-backdrop`，影响强调色、标签与地图底图。
- **地图氛围**：使用本地生成的暗色地牢底图作为 `map-stage` 背景；网格、墙、门仍由数据/SVG 渲染，几何保持准确。
- **棋子头像**：用 Qwen-Image-2.1 生成 10 张 512×512 半身像，转 256 webp；玩家（战士/游侠/牧师）、沈鸢、洛恩、哥布林近战/弓手、祭坛守卫、伊蕾娅、米咕。
- **地图棋子**：SVG `clipPath` 圆形裁切 + 阵营描边 + HP 条；图片缺失时 `onerror` 回退到原有字形。
- **跑团能力**：能力按钮按 `abilityIds` 渲染；队伍卡显示能力资源或射程；背包显示当前武器与伤害。
- **地图标题**：改为「冒险地图 / N 个已发现地点」，不再写死「钟塔地基」。
- **仓库整理**：绝对路径改为环境变量/占位符；生成产物与模型不进仓库；推送 GitHub。

## 生成实测（Qwen-Image-2.1）

- 10 张 512×512、24 步头像：**每张 28–58s**。
- 本次加载 445s（同时运行无头浏览器占用内存导致偏慢；正常约 45–120s）。
- 产出：`tools/art/out/tokens/`（git 忽略），UI 使用 `public/art/tokens/*.webp`（10 张，约 60KB）。
- 一致性：固定风格块 + 固定 seed + 方形构图 + 深色中性背景，UI 圆形裁切。
