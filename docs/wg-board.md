# 战场棋盘：与官方设计的对照

## 结论

之前确实没有棋盘交互，只有遭遇文字卡；这次补了基础棋盘，但要说清楚：它不是官方模组原图的复刻，也不是完整的战术层。

## 官方口径

- 《怒火与荣耀》核心规则以**米**为距离单位，武器有短距、中距、长距三段；超过长距自动失手，长距目标防御加 2。
- 核心书提供**可选**的微缩模型规则：一个方格约代表 2 米；不使用模型也能正常跑团。
- Graveyard Shift 原档是调查/叙事模组，文字描述距离与地点，没有给出一张必须按格走的战术地图。

## 和原档对不上的地方

- 原档没有战术地图，所以棋盘是**我们加的展示层**，不是“原档自带棋盘”的还原。
- 原档的掩体、视线和遭遇细节没有被完整转成地图数据。
- 移动不消耗动作，这是为了先跑通可视化、避免半成品规则；正式化前需要补行动经济。

## 验证

- `tests/wg-session.test.mjs`：移动坐标写回、重新读取仍存在。
- 浏览器：棋子渲染、方向键移动、拖动棋子（手工验证，棋子从 6/8 米拖到 9/11 米）。
- 攻击日志现在会显示双方距离与远近修正。


## 美术层

- 底图：本地图像模型生成的俯视墓园庭院（湿石板、骨堆、破败石棺、冷色月光与暖色提灯），原创素材，不使用规则书插图。
- 格线：两米一格，低透明度覆盖；不画每格数字。
- 棋子：圆形底座；我方冷蓝双环，敌方赤红虚线外环；选中金环，拖动时放大并加深阴影。
- 信息：棋子悬停或选中显示姓名；受伤、燃烧、濒死用角标“伤/燃/倒”。
- 距离：选中棋子与目标之间有虚线，旁边浮出“距离 + 近/中/远距”。
- 标注：棋盘底部明确写“战斗可视化层 · 非原档地图”。
- 兼容：没有底图时退回深色石地渐变，规则与棋子不受影响。
