# 跑团页人机交互检查

日期：2026-10-23
范围：`/games/wrath-glory` 跑团页；共用外壳只处理了同类标题与品牌文案。

## 1. 可读性

| 项目 | 当前值 | 结论 |
|---|---|---|
| 正文 | 16 像素 / 行高 1.7 | 通过 |
| 聊天叙述 | 15 像素 / 行高 1.75 | 通过 |
| 场景正文 | 15 像素 | 通过 |
| 行动记录 | 13 像素 | 通过 |
| 状态标签 | 12 像素 | 通过 |
| 角色名 | 16 像素 | 通过 |
| 按钮 | 14 像素 / 最小高度 40 像素 | 通过 |

次要文字颜色从 `#6f7886` 提升到 `#8b95a6`，提高暗色背景下的辨识度。未做自动化对比度扫描；这是本轮已知限制。

## 2. 点击与键盘

- 主要按钮最小高度 40 像素；左栏图标 44×44；侧栏页签 40 像素。
- 保留浏览器原生焦点环，并补 `:focus-visible` 2 像素描边。
- 输入框支持回车发送；`Shift + 回车` 保留换行。
- 发送期间按钮禁用；请求结束焦点回到输入框。
- 侧栏页签可用键盘聚焦与回车切换。

## 3. 聊天流

- 消息区带 `aria-live="polite"`。
- 只有用户已经在底部时才自动跟随新消息；上翻阅读历史时不抢滚动。
- 离开底部后出现“回到底部”按钮。
- 失败信息写入聊天记录和主持人区域，不弹窗。
- 玩家发言、主持人叙述、规则结算分成不同气泡。

## 4. 布局

- 1440 宽度：三栏常驻，中央区域超过 1300 像素。
- 1920 宽度：三栏常驻，中央区域超过 1700 像素。
- 390 宽度：单列，无横向滚动。
- 没有敌人时隐藏“目标”栏，不再留下空列。
- 左侧栏提供队伍、遭遇、线索、记录入口；右侧面板按页签切换。

- 状态标签不小于 12 像素
- 发送按钮高度不小于 40 像素
- 侧栏页签高度不小于 40 像素

## 6. 已知限制

- 未接入专业读屏软件逐项验收；`aria-live` 与语义标签已加，但完整无障碍审计仍需单独做。
- 移动端侧栏不是抽屉，而是排在聊天下方；没有焦点陷阱。
- 对比度未做自动化数值扫描。


## 7. 日志可读性（本轮新增）

原日志的问题与处理：

| 原样 | 现在 | 原因 |
|---|---|---|
| 每条检定前重复【序章 · 第一幕】标题 | 同一场景只显示一次场景分隔标题 | 重复标题占据聊天流 |
| `intellect + investigation`、`DN 3` | 智力＋调查、难度 3 | 可见文本统一中文 |
| 一整句“进行……检定……N 个图标……” | 可折叠检定卡：技能 · 成功/失败 · 成功数/难度 | 一眼看清结果，展开才看骰面 |
| 两次相同的觉察失败 | 卡片标注“第 2 次” | 不隐藏尝试，但能区分重复 |
| 线索只出现在日志里 | 同时写入右栏“线索”页签 | 玩家不需要翻日志确认 |

检定卡使用原生 `details/summary`，键盘可聚焦，回车或空格展开；默认折叠，避免刷屏。旧存档中的英文日志在渲染时也会被转换为中文，并同样生成检定卡。
