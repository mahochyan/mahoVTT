# v0.1 实现架构与实际边界

## 运行栈

严格 TypeScript 源码，预编译 ES modules；Node 原生 HTTP、fetch、crypto、node:sqlite；浏览器原生 JavaScript、CSS、SVG；Node test runner 与 Python Playwright。不是 Next/React/Prisma/Zod 实现。运行时零第三方生产依赖，开发重编译才需 TypeScript 与 Node 类型包。

本版以可运行交付为优先，没有把无法安装验证的包作为必需依赖。未来迁移 UI 框架可以复用引擎和契约，但不是一键等价替换。

## 数据流

```text
客户端按钮 / 自由文本
    → 保存请求、幂等检查、取得带 epoch 租约
    → 事务外模型计划（按钮跳过）
    → 校验角色权限、目标、位置、动作资源
    → 规则引擎生成新状态、事件和骰子
    → 短事务提交：版本 CAS、状态与镜像行、事件、骰子、claims、facts
    → 释放结算租约
    → 确定性事实卡与状态
    → 自由文本请求继续生成流式叙事
```

引擎是无数据库副作用的状态变换；非法命令不会提交局部改变。不是完全以事件归约重建状态的事件溯源平台：canonical state_json 是权威结构化快照，actors/objects 维护事务内镜像，events 保存审计事实。不能宣称本版可从任意事件片段恢复全部世界。

## 表与状态

campaigns：状态 JSON、版本、租约；actors/objects：查询与审计镜像；turns：请求ID/哈希、来源、双状态、计划、已结算事实、上下文快照、叙事尝试；events：战役顺序；dice：实际结果；claims：来源唯一性；migrations：版本记录。

主线与可选任务由稳定 flags 和对象 ID 驱动。不会使用模型生成的中文名作为外键。

SQLite 使用 WAL、外键与 busy_timeout；每次写事务很短，网络请求不在写事务内。一个数据目录只允许一个服务进程，PID 文件防误启动；这不是多机服务部署方案。

## 幂等与恢复

相同 requestId 和请求内容返回原回合；同 ID 不同内容拒绝。旧版本拒绝。租约持有者、epoch、有效期、状态版本与 pending 状态共同校验。

已结算叙事失败：保留游戏结果，使用已保存的事实与当时上下文重试，不重掷骰。叙事尝试独立 CAS，旧流不能覆盖新尝试。导入导出保存这些上下文，但绝不包含 API key。

进程重启：待处理的未结算请求标为失败，已提交保留；未完成叙事标失败。AI 角色回合由战斗 activation 序号和持久化请求继续，不依赖浏览器时钟。

SSE 是展示通道。浏览器保留原请求标识，连接中断先查询，不默认创建新行动。前端比较状态版本防倒退。文字片段不逐片落库，部分未完成措辞可能需要重新生成。

## AI 与记忆

计划使用 chat/completions 非流式 JSON，最多一次格式修复。DM 有已揭示的主持背景，队友只看队伍可见信息。role/source 由服务器设定，模型不能以 actorId 随意控制玩家或敌人。

记忆采用规范状态、固定世界书、最近回合与每八个版本刷新一次的确定性事实摘要。字符预算是保守近似，不是精确 tokenizer；没有向量检索和额外 LLM 语义摘要。

输出只读取 content，独立 reasoning_content 不展示。流式正常结束依赖 finish_reason。协议兼容需实测，特别是本地推理服务返回方式。

## 安全边界

只绑定 127.0.0.1；Host 和写请求 Origin 检查；不提供登录/多人，不应公网转发。所有 HTML 文本转义，叙事不执行 Markdown HTML。配置在服务端文件，读取设置不回传密钥。导出虽无密钥，但包含完整剧情与秘密，分享前确认剧透范围。

导入校验格式、校验和、规范实体、地图位置和资源范围，创建新战役副本。正式存档文件不应当作不可信代码执行。

## 目录迁移

start.cmd 只在自身文件夹工作，不会触碰旁边项目。不能通过本包远程写入你的 E 盘。请解压出完整 sagas 文件夹。端口和 DGX 配置由本地设置决定，data 由首次运行创建。
