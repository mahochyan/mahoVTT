# 灰灯纪事 · 无声钟塔

**一个可以直接运行的中文 AI 跑团平台：多战役工作台、角色名册、世界与内容库，版本 0.2.0。**

工作台（`/`）管理战役与角色；进入战役后，你扮演自己的角色，与 AI 同伴探索五个房间，击败守卫，调查维护款的去向，带回调谐钥匙。可以直接点击地图与按钮，也可以连接 OpenAI 兼容模型，以自然语言表达行动。

仓库：https://github.com/mahochyan/mahoVTT

## 当前进度（v0.2）

- 平台：工作台、战役列表/详情、角色名册、四步创建向导、世界库、内容库、设置。
- 跑团：沿用现有规则引擎；顶部导航与平台统一；世界封面/背景与角色棋子头像。
- 视觉：中性「档案库」外壳 + 世界主题（强调色、封面、底图）；不绑定单一题材。
- 测试：`npm test` 62 / 62；`npm run test:browser` 15 / 15（Windows + Edge headless，无 Edge 时自动跳过）。
- 验收：三档宽度截图与结论见 `docs/acceptance-v0.2.md`。
- 未完成：内容包与第二世界、Forge/社区/多人、完整浏览器自动化；详见 `docs/m2-report.md`。

## 先启动，再接 AI

1. 把项目放在任意本地目录，例如 `<项目目录>`。不会使用或修改相邻的其他项目。
2. 需要 Node.js 22.16 或以上，推荐已安装的 Node.js 24。**运行不需要 `npm install`、pnpm、Python、Docker 或云端账号。**
3. 双击项目目录中的 `start.cmd`。窗口保持打开，浏览器会自动打开本地网页。
4. 浏览器地址为 `http://127.0.0.1:3000`。默认规则演示模式可以直接游玩。
5. 在右上角点 **AI 设置**，切换到 **OpenAI 兼容接口**，填写地址、模型 ID 与可选密钥。
6. 点 **保存并测试连接**。如返回多个模型，在模型 ID 中选定一个，再点 **保存配置**。

终端运行也可以：

```powershell
cd <项目目录>
node scripts/start.mjs
```

`npm start` / `pnpm start` 直接运行预编译版本。修改源代码后才需要安装开发依赖和重新编译。

## 接入你的双 DGX / TensorFold

地址示意，不是你机器的真实地址：

```text
运行模式：OpenAI 兼容接口
API Base URL：http://你的DGX局域网地址:实际端口/v1
模型 ID：/v1/models 返回的确切 ID
API Key：本地服务不要求时留空
JSON 约束：先选择“仅提示词约束”
```

不需要为了此项目更换你已验证的 **DeepSeek 1017 EXL3 2.9bpw** 基线。这里没有预设 TensorFold 的端口或模型名称。

支持的协议是 `/v1/models` 与 `/v1/chat/completions`。结构化计划使用非流式 JSON，叙事读取 `choices[].delta.content`，忽略独立的 `reasoning_content`。不同后端的约束 JSON、思考开关、上下文上限仍需真实测试。

配置路径二选一：

- 推荐：网页 AI 设置，保存到服务端 `data/settings.json`。
- 或首次启动前复制 `.env.example` 为 `.env.local` 并填写；已保存的网页配置优先于环境文件。

示例环境配置：

```dotenv
AI_PROVIDER=openai
AI_BASE_URL=http://你的DGX地址:实际端口/v1
AI_MODEL=你的确切模型ID
AI_API_KEY=
AI_JSON_MODE=off
AI_TIMEOUT_MS=45000
PORT=3000
```

应用服务端连接 DGX，浏览器只连接本机应用，因此密钥不进入前端，也不要求浏览器直接访问 DGX。

### 实机兼容性检查

在完成配置后运行：

```powershell
node scripts/ai-ping.mjs
node scripts/ai-ping.mjs --samples 20
```

脚本检查模型列表、计划格式、引擎合法性、中文流式输出，报告写到 `data/compatibility-report.json`。注意：一次模型列表请求成功不等于二十次行动计划已经通过；模拟模式的结果也不是 DGX 测试。

本包**没有连接你的实际 DGX**，不能把随附的模拟接口测试当成实机兼容性承诺。

## 第一局怎么玩

创建角色后，点地图下方的 **伊蕾娅 · 接受委托**。浅色格子是本次可达范围，点击地面移动，靠近门后使用相邻互动。点击红色敌人棋子攻击；进入战斗后，一轮有六格移动、一个动作和一个附赠动作。行动完点击 **结束回合**。

药水与战士回气消耗附赠动作。队友会依次决策，敌人由规则策略驱动。模型故障时队友使用有日志标记的保守规则策略，战斗不会只因为模型离线而永久停住。

剧情输入框可以输入“与沈鸢交谈，问她如何接近敌人”“调查面前的账簿”等。一次请求只执行第一个明确动作。模拟模式只识别有限关键词与移动坐标，**并不是免费离线大模型**；完整自由叙事需要接入你的模型。

`/r d20` 是自由骰，只记骰史，不会自动造成伤害或完成任务。真正的攻击和交互会自动使用相应的规则骰。

本项目是原创实现与原创美术界面，不包含 Shaping Sagas 的源码、商标素材或商业冒险内容，不宣称完整复刻其功能。

## 存档与隐私

- 自动存档：`data/sagas.sqlite`，每次已接受行动都提交事务。
- 导出：顶部“导出存档”。JSON 包含完整游戏状态与历史，**可能剧透**，不包含模型密钥。
- 导入：首页“导入存档”，创建新副本，不覆盖旧战役。
- AI 配置：`data/settings.json`，其中可能有明文密钥。仅服务端读取，不应公开此文件。
- 本机单用户：服务只监听 `127.0.0.1`，拒绝非本机 Host 和跨站写请求；没有远程账号认证，不要把它直接暴露到公网。
- 一个数据目录只允许一个服务进程运行；`server.lock` 防止不同端口误用同一份存档。
- 运行中的 SQLite 不应仅复制主 `.sqlite` 文件备份，WAL 里也可能有已提交内容。优先用网页逻辑导出；要整目录备份，先关闭服务再复制整个 `data`。

## 限制与后续边界

这是一段完整的小型冒险，不是开放世界平台。没有多人、账号、内容市场、地图生成、语音、纸娃娃、完整 5e 或动态创建职业/NPC/任务。地图采用房间级迷雾，不是精细动态光照。状态时长系统仅保留扩展结构，目前主要条件为倒地。

长期记忆使用规范实体、事件记录和确定性事实摘要；没有再调用一个模型进行语义摘要，也没有向量数据库。叙事不会改变状态，但生成的自由文字仍可能与事实有偏差，应以事实卡为准。

并未完成你的 Windows 环境实测、真实 DGX 二十次验收或连续三小时人工游玩；不能据此宣称达到原计划的最终 M5 验收。模型耗时、首字延迟、token 使用量与策略质量需要你接入后测量。本包是可运行的 v0.1 首版，而不是生产级保证。
